---
title: Analytics
description: Umami on the public pages only, no cookies.
---

Umami runs on the public pages of `apps/web` only: the landing page, privacy, terms and status. Everything else is never tracked: the dashboard, the guest capture pages and the docs previews have no Umami script, and a new page in `apps/web` stays untracked until it is added to `PUBLIC_PATHS` in `apps/web/components/umami-script.tsx`.

Umami sets no cookies and stores no personal data (no ip, no user id). The script honours the browser's do not track setting and drops the query string, and it only loads after the visitor accepted the consent banner.

The banner (`@ritorno/compliance/banner`) is a bar at the bottom of web and dashboard pages, in the page language (`consentBanner` messages). While it shows it sets `--consent-banner-height` on `<html>`: the body is padded by it and bottom-fixed bars (phone tabs, sidebar, feedback button) use `bottom-consent` to sit above it, so it never covers a form button. A new fixed bottom element needs the same.

| Key | What it is |
| --- | --- |
| `NEXT_PUBLIC_UMAMI_URL` | base url of your Umami, defaults to Umami cloud |
| `NEXT_PUBLIC_UMAMI_WEBSITE_ID` | website id, empty means no analytics |
