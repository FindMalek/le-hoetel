Every important choice gets a short record: context, decision, why, why not, consequences, and when to revisit it. Add a new file in `apps/docs/content/docs/decisions` and list it in `meta.json` when a PR changes a decision.

## The table

| We do | We skip | Why | Record |
|---|---|---|---|
| Capture first (QR page, CSV import) | PMS connector in V1 | Hotels may hold no contacts, the Xlia API is unknown, integration is the top competitor complaint | [Capture first](/docs/decisions/capture-first) |
| Recognition and simple perks | Points and tiers | Guests think programs lost value, less to build | [Recognition over points](/docs/decisions/recognition-over-points) |
| Branding is config | Custom code per client | Custom work turns a SaaS into an agency | [Branding is config](/docs/decisions/branding-is-config) |
| One bucket, prefix per hotel | Bucket per client | Less ops, separate later if a hotel asks | [One bucket, prefix per hotel](/docs/decisions/one-bucket-prefix-per-hotel) |
| Email and WhatsApp first | SMS on day one | SMS is one way, sender ID is slow, WhatsApp is where Tunisians talk | [Email and WhatsApp first](/docs/decisions/email-and-whatsapp-first) |
| Small local hotels first | Tour operator resorts first | The owner decides fast, locals are reachable | [Small local hotels first](/docs/decisions/small-local-hotels-first) |
| Free pilot then paid | Building for months before selling | Prices are untested | [Free pilot then paid](/docs/decisions/free-pilot-then-paid) |

## Architecture decisions

| We do | We skip | Record |
|---|---|---|
| A hotel is an organization | A custom tenant model | [Hotel is an organization](/docs/decisions/hotel-is-organization) |
| Guests are hotel-scoped rows | Guests as auth users | [Guests are not auth users](/docs/decisions/guests-are-not-auth-users) |
| Append-only consent log | A consent flag on the guest | [Consent log is append only](/docs/decisions/consent-log-append-only) |
| Deleting a guest removes everything, the audit keeps a hash | Keeping consent events as proof | [Guest delete is a hard delete](/docs/decisions/guest-delete-is-a-hard-delete) |
| Signed unsubscribe link per guest, hotel and channel | A token table, or a login to unsubscribe | [Unsubscribe links are signed tokens](/docs/decisions/unsubscribe-links-are-signed-tokens) |
| Machine translate fr and ar once per release | A translation pull request per merged PR | [Languine per release](/docs/decisions/languine-per-release) |

## Open decisions
